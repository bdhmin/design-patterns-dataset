# Civic Holdings Register: front end

Collection-management front end for the City of Harrow Bay's municipally owned public art. Built with React, TypeScript and Vite. There is no backend: all data is mock data in the repo, and proposal changes are saved in the browser's localStorage.

## Commands

```bash
npm install
npm run dev              # local dev server
npm run build            # type-checks, then writes the static site to ./out (entry: out/index.html)
npm run generate-data    # regenerates src/data/works.json (seeded, deterministic)
```

`out/` uses relative asset paths, so it can be served from the root of any static file server with no rewrites.

## What is in the app

- **Eastvale Branch Library** (opens by default). Proposal builder for the January 2027 opening.
  - Candidates: every available work that fits at least one space, with per-space eligibility (RR / CA / EA). Filter by space, medium, condition, Eastvale artists, shortlist; search; sort.
  - Proposal: 12 slots, each assigned a space and a wall. Live checks for the director's requirement (at least 6 by Eastvale-area artists), wall lengths, and blocking conflicts. Export CSV, print, reset.
  - Work detail drawer: fit numbers per space, loan and promise conflicts, full record.
- **Collection register**: all 1,412 works, filterable and sortable, with CSV export of the current filter.

## Rules

Rules and clearances live in `src/lib/constants.ts`; the eligibility engine is `src/lib/rules.ts`.

Availability (blocks every space):
- On hold for the Civic Center renovation.
- On loan or promised to another venue with a return date on or after 21 Dec 2026 (`FREE_BY`).
- Condition "Needs Treatment".

Warnings (eligible, but flagged):
- Condition "Fair".
- Condition last assessed more than 3 years ago.
- On loan or promised, but back before 21 Dec 2026.
- Children's Area: wall height not supplied by Facilities.

Space rules:
- **Reading Room** (south wall, 640 × 280 cm): works on paper, photographs and textiles are ruled out (direct sun).
- **Children's Area** (three walls, 310 cm each): hung works only; fragile works must be at least 120 cm tall.
- **Entry Atrium** (420 × 500 cm): size and clearance only.

Fit: a work fits a wall if its width plus 20 cm at each end fits the wall length, and its height plus 30 cm fits the wall height. Works on the same wall need 40 cm between them.

## Assumptions to confirm

These were decisions made without the source system's schema or the director's written brief. Each is a single constant or small function to change.

1. **Review date** is Friday 20 Nov 2026 (`REVIEW_DATE`). 13 Nov 2026 is itself a Friday.
2. **Mounting and fragility** are not in the register fields described in the brief. The mock records carry `mounting` ("Wall-hung" / "Free-standing") and `fragile`. Fragility is derived from glass or ceramic materials.
3. **Children's Area height rule** is read as the work's own height (fragile works must be at least 120 cm tall), not its hanging height.
4. **Wall dimensions** are read as length × height (6.4 m × 2.8 m; 4.2 m × 5.0 m). The Children's Area walls have no height given, so height is not verified there.
5. **Light-sensitivity class** is shown but not used beyond the medium rule the brief gives for the Reading Room.
6. **Clearances** (20 cm ends, 40 cm between works, 30 cm above and below) are my estimates.
7. **Default condition filter** is "Good or better" in the library candidate list.

## Data

`src/data/works.json` is generated by `scripts/generate-collection.mjs`. All records are fictional mock data except that Tidewater at Dusk (HB.1994.017) and Market Day (HB.2011.088) match the brief. The generator's counts are checked on every run: 1,412 works, 63 Eastvale-artist works, 14 on hold.

The opening state (`src/data/seed.ts`) is an invented in-progress proposal: seven works placed, 15 shortlisted. It is there to show the project one week before the review.
